Form Guide
Case Information

Provide basic information about the case including title and case number. The case number should be unique within your firm.

Status and Type

Select the appropriate status and case type. This helps in organizing and filtering cases effectively.

Client Assignment

Select the client associated with this case. Only active clients from your firm will be shown.

Lawyer Assignment

Assign one or more lawyers to this case. Multiple lawyers can work on the same case.

Important Dates

Set the start date and optionally the end date for the case. This helps in tracking case duration.

Quick Tips
Use descriptive case titles for easy identification
Keep case numbers consistent with your firm's naming convention
Assign lawyers based on their expertise and availability
Regular case updates improve client communication
