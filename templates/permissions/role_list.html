System Roles

System roles are predefined roles that come with the system:

  • Admin: Full access to all system features
  • Lawyer: Can manage cases, clients, and documents
  • Paralegal: Can view and edit but not delete
  • Billing Manager: Can manage all billing operations
  • Read-only Staff: Can view but not edit
