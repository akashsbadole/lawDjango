About Permissions
Permission Modules

Permissions are organized by functional modules:

  • Clients: Manage client information
  • Cases: Manage case files and proceedings
  • Documents: Manage document storage
  • Billing: Manage invoices, payments, and time entries
  • Users: Manage user accounts
  • Roles: Manage role assignments
Permission Types

Each module typically has these permission types:

  • View: Can view items in the module
  • Add: Can create new items
  • Change: Can edit existing items
  • Delete: Can delete items
